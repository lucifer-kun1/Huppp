# 🚀 Huppp: Discord All-In-One Automator (2026)

A fully humanized, zero-proxy automated Discord account creator and voter. Designed for server giveaways, participation, and voting.

## ✨ Features
- **Humanized Behavior:** Bezier curve mouse movements and variable typing speeds.
- **Auto-Customization:** Automatically sets Bios and Profile Pictures (Avatars).
- **Auto-Vote:** Joins servers and reacts to messages automatically via Discord API.
- **Stealth:** Uses `undetected-chromedriver` to bypass bot detection.

## 🛠️ Setup Instructions

1. **Clone the Repo:**
   ```bash
   git clone [https://github.com/lucifer-kun1/Huppp.git](https://github.com/lucifer-kun1/Huppp.git)
   cd Huppp

  2. Configure the Script:
`Open main.py and edit the following variables at the top:`

CAPTCHA_KEY: `Your 2Captcha API Key.`

SERVER_INVITE:` Your target server's invite link.`

Add Avatars:
`The script creates an /avatars folder automatically. Place your .jpg or .png images inside that folder to enable profile picture customization.`

Run the Script:
`python main.py`
